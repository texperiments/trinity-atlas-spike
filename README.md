# Trinity atlas spike

A test page for the 3D anatomical atlas of the Trinity Performance OS: three data sets, one viewer,
switch at the bottom. Drag to orbit, pinch to zoom, tap a structure to name it.

Built from `tools/atlas-spike/` in the TrinityVert repository; this repository only holds the
published files.
